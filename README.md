# NYC Mechanical Engineering Internship Tracker (GitHub Pages copy)

This is a static HTML/CSS/JavaScript copy of the tracker. It has no server or database; role edits, application statuses, saved searches, and comparison selections are stored in the current browser only.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository and upload these four files to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment and open the URL GitHub shows on the Pages settings screen.

This copy does not change the existing private ChatGPT Site. Updates to one copy do not automatically update the other. Keep edits to `index.html`, `app.js`, and `styles.css` together, then commit and push them to GitHub to update the Pages copy. The `app.js` file contains the initial opportunity list and the interactive tracker behavior.
